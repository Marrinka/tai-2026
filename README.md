# Тёплый январь · Таиланд 2026–2027

Планировщик зимовки для двоих. Здесь собраны перелёты, жильё, маршруты по Бангкоку и югу Таиланда, карта, календарь и чек-лист. Выбранные билеты, жильё и платные активности входят в общий бюджет. [Открыть сайт](https://thai-winter-notebook-2027.marinkav-dev.chatgpt.site/)

[План поездки](app/trip-plan.json) хранит наш выбор и правки из календаря. Его можно редактировать кнопками самого планировщика. В первый раз понадобятся Git и Node.js 24 LTS с npm. Для отправки изменений владелица репозитория должна дать вашему аккаунту GitHub доступ на запись.

## Первый запуск

Выполните команды в терминале. На Windows подойдёт PowerShell.

```sh
git clone https://github.com/Marrinka/tai-2026.git
cd tai-2026
npm run install:ci
npm run plan:html
```

Откройте **`outputs/trip.html`** двойным щелчком. Это ваша редактируемая копия плана из Git. Для её работы достаточно браузера. Календарь, бюджет и встроенные фотографии доступны без интернета. Для карт и перехода по ссылкам нужен интернет.

## Как внести правки и поделиться ими

1. **Перед каждой новой сессией** откройте терминал в папке `tai-2026` и выполните `git pull --ff-only`, затем `npm run plan:html`. После обновления `package-lock.json` сначала повторите `npm run install:ci`. Откройте заново полученный `outputs/trip.html`.
2. **Измените план в браузере.** Например, добавьте событие в календарь с ценой за двоих и проверьте итог в разделе «Расходы». Нажмите **«Скачать HTML»** вверху страницы. Именно в скачанном файле будут последние правки.
3. **Перенесите правки из скачанного файла в Git.** После `--` укажите путь к файлу из «Загрузок». Можно перетащить файл в окно терминала, чтобы подставить его путь. Пример для macOS и Linux:

   ```sh
   npm run plan:import -- "$HOME/Downloads/thailand-winter-2026-11-15-120000.html"
   git diff -- app/trip-plan.json
   ```

   В PowerShell можно так же указать полный путь в кавычках. Импорт берёт выбранные рейсы, жильё, цены, события, расходы и отметки чек-листа. В сравнении Git видны конкретные изменения. Если результат неожиданный, проверьте, какой файл импортировали, до коммита.

4. **Отправьте правки со своим описанием.**

   ```sh
   git add app/trip-plan.json
   git commit -m "Добавить каяки на островах Хонг в календарь"
   git push
   ```

Второй участник получит эти изменения, повторив шаг 1. HTML в папке `outputs` можно пересобрать из Git в любой момент. Если редактируете одновременно, начинайте с одной свежей версии. Если Git отклонит отправку из-за чужого коммита, выполните `git pull --rebase`. При конфликте сверьте оба варианта события или суммы, затем выполните `git add app/trip-plan.json`, `git rebase --continue` и `git push`.

## Как обновить копию с опубликованного сайта

Откройте **вашу полную ссылку на общий план**. Дождитесь статуса **«Сохранено на сайте»** и нажмите **«Скачать HTML»**. Затем выполните шаги 3 и 4. На сайте общий план хранится в базе данных, в GitHub — в `app/trip-plan.json`. Перенос между ними делается явно. Команда `git push` обновляет GitHub. Для изменения общего календаря на действующем сайте используйте его интерфейс, а для публикации новой версии самого приложения — Sites.

Репозиторий публичный. Перед коммитом проверьте заметки и ссылки в `git diff`. Полную ссылку с ключом редактирования передавайте друг другу лично.

## Как изменить сам сайт

Чтобы добавить жильё, изменить описание маршрута или оформление, запустите сайт из папки проекта:

```sh
npm run dev
```

Откройте адрес, который напечатает терминал, обычно <http://localhost:5173>. При сохранении исходников страница обновится. Для остановки нажмите Ctrl+C. В режиме без общей ссылки правки через интерфейс сохраняются в этом браузере. Перенести их в Git можно той же кнопкой «Скачать HTML» и командой `plan:import`.

При редактировании каталогов сохраняйте существующие `id`. По ним календарь и бюджет находят конкретные рейсы, жильё и активности. После правок запустите `npm run build`, проверьте `git diff` и добавьте в коммит изменённые исходники. Другой участник может посмотреть результат через `npm run dev` или собрать свежую автономную копию командой `npm run plan:html`.
